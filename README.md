Projeto	Descrição	Tecnologias
📌 Previsão de demanda elétrica com aprendizado profundo (Deep Learing). Nesta iniciação científica tinhamos como objetivo utilizar do deep learning para prever o consumo de demanda elétrica de uma residência, analisando o seu consumo de energia por cada aparelho, a geração por painéis solares, e incluindo variáveis exógenas, como o horário do dia, estação do ano, clima, etc. Devido o grande custo computacional para o treinamento deste modelos, desenvolvi uma técnica, que divide os clientes de treinamento em grupos de perfis semelhantes para que perfis muito distintos não atrapalhem a criação de um modelo global que represente os demais. Para mais detalhes de como funciona a técnica empregada acesse a pesquisa.
